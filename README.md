# 知时 · 东方人生导航 MVP

这是 Project ZHISHI 的第一轮可运行产品骨架，当前为无依赖的响应式 Web 原型，用于快速验证核心信息架构与交互。

## 当前覆盖

- Daily / Journey / Year 三模式主导航
- 今日定向、今日行动和状态更新
- “我现在有点乱”三步澄清流程
- 人生章节时间线
- 一年导航年度总览、季度节奏、五个领域和月度导航
- 通用“为什么这么判断？”证据链展开
- 安全边界说明与本地演示数据

## 本地运行

```bash
npm run dev
```

然后打开 `http://127.0.0.1:4173/`。

当前使用演示数据，尚未接入真实账户、后端 API、八字计算服务、模型 API 或数据库。
