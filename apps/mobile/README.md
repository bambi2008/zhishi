# 知时原生移动端

这是基于 Expo + React Native 的 iOS / Android 工程，和根目录的 Web MVP 共用产品语言，但不共用 Web DOM。

## 运行

```bash
npm install
npm run start
```

然后使用 Expo Go 扫码，或运行：

```bash
npm run android
npm run ios
```

如需连接本地 FastAPI，在 `.env` 中设置 `EXPO_PUBLIC_API_BASE_URL`。Android 模拟器通常使用 `http://10.0.2.2:8000`，iOS 模拟器使用 `http://127.0.0.1:8000`；真机需要改成电脑在局域网中的地址。

## TestFlight 准备

应用已配置 iOS bundle ID、构建号、无豁免加密声明、App 图标、启动图与 EAS 的 `preview` / `production` 构建档。任何 EAS 构建都会先执行生产环境检查，缺少 HTTPS API 地址时直接失败，避免上传一个只能访问 `127.0.0.1` 的无效版本。

```powershell
$env:EXPO_PUBLIC_API_BASE_URL="https://<production-api-host>"
npm run testflight:check
npx eas-cli@latest build --platform ios --profile production
npx eas-cli@latest submit --platform ios --profile production
```

第一次构建前仍需登录 Expo 与付费 Apple Developer 账号，由 EAS 创建/读取签名证书与 provisioning profile；App Store Connect 中也必须先建立与 `com.bambi2008.zhishi` 对应的应用记录。Apple 登录、2FA 和协议接受不能写入仓库。

底部“命盘”入口已经连接真实 `zhishi-bazi-core`：用户搜索出生城市即可自动填写 IANA 时区与经纬度，随后展示四柱、太阳时校正、最近节气边界、误差替代结果和双引擎审计状态。稳定命盘接口为 `POST /api/v1/bazi/charts/calculate`，带当前时刻的上下文接口为 `POST /api/v1/bazi/context/current`。

用户选择传统排运性别和起运算法后，结果会继续展示顺逆依据、起运年龄、起运日期、当前所在大运、当前立春流年、当前十二节流月、下一次交接时刻以及八步大运时间轴。默认采用分钟折算法；传统天数/时辰折算法可显式切换，界面不会把流派差异隐藏在后台。

出生时间精度可选择“精确”“约 ±30 分钟”或“约 ±60 分钟”。非精确输入仍按用户填写的具体时刻正常展示四柱、大运、流年和流月，同时保留误差区间候选；填写页和“安全与使用条款”会明确提醒实际出生时刻偏差可能改变结果。

底部导航收敛为“今天 / 回看 / 今年 / 命盘”四项，并使用 iOS SF Symbols 与 Android Material Symbols 的原生图标映射。“我现在有点乱”不再单独占一项导航，也不再要求新用户先填写三步表单；它是“今天”对话里的快捷问题。既有事实梳理不会丢失，仍可在“回看”搜索、编辑、导出和删除。

“今天”和“今年”共用同一个 DeepSeek 回答优先对话。每轮响应必须先提供清楚的直接答案、一个可观察动作、具体执行时间、完成标准、2—3 个场景案例及风险提醒，然后只问一个会显著改变建议的问题。用户回答后，服务端要求模型引用最新补充并重写整份建议，不能只在旧答案后追加一句。今天限定为未来 24—72 小时的可逆动作；今年限定为未来 30—90 天的计划、检查点和决策条件，不预测年度事件。

“今天”页仍允许用户主动记录 1–5 级能量、1–5 级压力、当前感受、关注领域以及可选的重要事件和备注。同一本机日期只保留一条，可反复更新并保留最初创建时间。今天对话在没有命盘时也能只根据本轮消息和今天状态回答；如果本机已有命盘，则只附带服务端重新计算并审计通过的最少量命盘与周期事实。“今年”对话必须有一张已保存命盘。

涉及事业或关系时，模型不能编造他人动机或替用户做重大决定；涉及投资时，只能提供目的、最大可承受损失、流动性、独立信息源、分散、冷静期、退出条件和复盘节奏等流程保护，不得推荐具体资产、买卖时点、杠杆、借款或预期收益。每轮都展示其实际引用的计算证据和现实证据。

新对话最多接受五轮回复，完整对话和 AI 输出默认只存在当前页面，关闭后清除。输入框上方持续显示本轮会发送的数据；点击发送即是该轮主动确认，不再增加一张打断沟通的同意页。App 不包含 DeepSeek API Key，全部模型调用由后端代理。旧事实梳理仍按原有本机保存规则保留，编辑原始事实会移除旧 AI 综合结果，避免旧结果继续绑定已经变化的输入。

命盘不会自动持久化。用户点击“保存”后，出生资料和计算结果同样通过 AsyncStorage 保存在当前设备。命盘、每日状态和事实梳理都属于应用沙盒内的未单独加密设备存储，不应用于共享设备；卸载 App、清除应用数据或主动删除后无法恢复。后续接入账户同步时应改用服务端加密存储和明确的删除机制。

出生资料提交前会显示美国与欧洲隐私基线提示：当前 MVP 的计算 API 不主动持久化请求，不销售数据、不投放行为广告；命盘、每日状态和旧事实梳理仅在用户主动点击保存后写入本机。新统一对话会在输入框上方即时披露：发送本轮消息；若今天已有状态则附带该状态；若本机已有命盘则附带最少量已审计命盘与周期事实。完整欧美上线草案见根目录 `TERMS_OF_USE.md`、`PRIVACY_NOTICE.md` 和内部 `LEGAL_NOTICE.md`。

Windows 可以开发 Android / Expo Go；iOS 原生编译需要 macOS + Xcode。
